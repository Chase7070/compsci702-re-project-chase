# Fortify 迭代日志 · Chase7070 · fog v1.2  
**文件：** `2025-5-12_Chase7070_fog_v1.2.md`  
**主题：** 将 Retrofit 注解中的 endpoint path 移出，改为 `@POST` + `@Url` + 运行时路径分片（配合既有 StringFog 处理自有包字面量）。

---

## 1. 目的

- 既有 StringFog 对 **`@POST("auth")` / `@POST("generate_image")` 注解参数** 通常无法处理，JADX 仍可直接搜到完整 path。
- 本次仅降低 **注解内 endpoint 字面量** 暴露：接口上不再出现上述完整字符串；path 在 **`EndpointProvider`** 中由短片段拼接，便于进入方法体常量池并由 StringFog 处理（取决于插件与 R8 行为）。

---

## 2. 做了什么（文件）

| 文件 | 变更 |
|------|------|
| `app/.../data/network/EndpointProvider.kt` | **新建**：`authPath()`、`generateImagePath()` 使用分片拼接（如 `"a"+"u"+"t"+"h"`，`"generate"+"_"+"image"`）。 |
| `app/.../data/network/ApiService.kt` | `@POST("…")` 改为 `@POST` + `@Url path: String`；`auth` / `generateImage` 签名增加 `@Url` 参数。 |
| `app/.../data/repository/ImageRepository.kt` | 调用处传入 `EndpointProvider.authPath()`、`EndpointProvider.generateImagePath()`。 |

**未改动（按约束）：** `BuildConfig`、`secrets` 注入、`NetworkModule`、`OkHttp` 栈、NSC、host allowlist、Gson model 与 `@SerializedName`、请求/响应体结构。

---

## 3. 为什么能减少 JADX 对 endpoint 的命中

- **注解 `RuntimeVisibleAnnotations`** 中不再包含 `"auth"` / `"generate_image"` 整串，反编译接口时关键词搜索命中率下降。
- 路径片段出现在 **`EndpointProvider` 方法体**（及调用点字节码）中，与 **`fogPackages = com.example.reverseengineeringbuildphase`** 一致时，StringFog 更可能将常量池替换为密文形态（仍以 release APK + JADX 实测为准）。

---

## 4. API 行为是否改变

- **HTTP 语义不变：** 仍为对同一 `baseUrl` 的相对路径 `auth` 与 `generate_image` 的 **POST**；请求体、响应解析与原先一致。
- **仅请求构造方式** 从「注解固定 path」变为「运行时传入相对 path」。

---

## 5. Retrofit `@Url` 风险

| 风险 | 缓解 |
|------|------|
| `baseUrl` 必须以 **`/`** 结尾，相对 `@Url` 不得以 **`/`** 开头，否则易出现双斜杠或解析错误。 | 项目约定与 `build.gradle.kts` 默认 `API_BASE_URL` 保持 **尾随斜杠**；`EndpointProvider` 返回无前导 `/` 的 segment。 |
| 误传绝对 URL 或错误 path 导致 404。 | 路径集中在 `EndpointProvider`，与后端约定一致；发布前做 **auth / generate_image** 联调。 |

---

## 6. 如何测试

```bash
./gradlew :app:assembleDebug
./gradlew :app:assembleRelease
```

真机或模拟器（配置有效 `secrets.properties`）：

1. **auth** 能拿到 signature（无异常进入 generate）。  
2. **generate_image** 能返回图片相对/绝对路径。  
3. **图片预览** 正常。  
4. **保存相册** 正常。

**静态验证：** JADX 打开 release APK，在 `ApiService` 中搜索 `generate_image`、`auth`（注解内）；预期接口声明处不再出现原 `@POST("generate_image")` 形式（`EndpointProvider` 内可能为分片或 fog 后形态，依 StringFog 为准）。
