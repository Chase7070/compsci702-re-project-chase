# 开发日志 · 2026-05-09

**主题：** Android 网络安全与出站策略加固（对照 V1 安全清单落地）  
**范围：** Manifest、Network Security Config、OkHttp 拦截器、图片 URL 校验、Coil / 相册保存统一网络栈、构建与文档。

本文档为**本次迭代**的过程与交付说明；技术细节与原理仍与 [2026-04-21.md](2026-04-21.md) 第 3～5 节互补。

---

## 1. 背景与目标

- 在现有单模块 Android 工程上落实：**关闭备份**、**禁止明文 HTTP**、**Release 不信任 user CA**、**出站 Host 白名单**、**图片 URL（HTTPS + 域名）校验**、**成功 GET 的 Content-Type 须为图片**。
- 保证 **Retrofit**、**Coil 预览**、**保存到相册** 共用同一 `OkHttpClient`，避免部分路径绕过策略。
- 更新 Fortify 说明与 README，便于课程提交与复查。

## 4. 配置提示（多域名/CDN）

若图片资源与 `API_BASE_URL` 不同 host，在 **`secrets.properties`**（勿提交）中增加：

```properties
ALLOWED_NETWORK_HOSTS=cdn.example.com,images.example.com
```

多个 host 使用英文逗号分隔，**不要**带 `https://` 前缀。
