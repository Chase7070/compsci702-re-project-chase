# 开发日志 · 2026-04-14

## 项目

ReverseEngineeringBuildPhase（Android Kotlin 原生，课程 Reverse Engineering Project — Build phase）

## 当日完成

- 初始化 Gradle 工程：`settings.gradle.kts`、`build.gradle.kts`、`app` 模块。
- 实现主流程 UI：Prompt 输入、`Generate` / `Cancel` / `Save`、Loading 与状态文案。
- 网络层：`Retrofit` + `OkHttp`，`AuthorizationInterceptor` 为 `/auth` 与 `/generate_image` 统一附加 `Authorization`。
- 业务编排：`ImageRepository` 先调用 `/auth` 获取 `signature`，再以 `{ signature, prompt }` 调用 `/generate_image`，解析 `image_url`。
- 展示与保存：`Coil` 加载图片 URL；`ImageSaver` 经 `MediaStore` 写入相册（Android 10+ 使用相对路径；低版本声明 `WRITE_EXTERNAL_STORAGE` maxSdk 28）。
- 状态与取消：`MainViewModel` + `StateFlow`，`Job.cancel()` 取消生成流程。
