# 开发日志 · 2026-04-15

## 项目

ReverseEngineeringBuildPhase（Android Kotlin 原生，课程 Reverse Engineering Project — Build phase）

## 当日完成

- **错误处理补全**：在现有工程上系统化接入空 prompt、`/auth` 与 `/generate_image` 失败、图片预览加载失败、网络超时与未知异常。
- **领域错误类型**：新增 `GenerateImageFailure`（`AuthFailed` / `GenerateFailed`），`ImageRepository` 分阶段捕获并包装，对空 `signature`、空 `image_url` 做校验；`CancellationException` 始终向上抛出，不吞掉协程取消。
- **统一文案映射**：新增 `NetworkErrorMapper`（`messageWithPrefix`、`messageForThrowable`），沿 `cause` 链识别超时、`HttpException`、DNS/连接/SSL 等；`HttpException` 读取 error body 时加 try/catch，避免二次崩溃。
- **ViewModel**：`MainViewModel` 用 `try/catch` 替代 `runCatching`，对 `CoroutineCancellationException` 更新 UI 后 **rethrow**；分别处理 auth / generate 失败并写入 `pipelineError`；新增 `onImageLoadStarted` / `onImageLoadSuccess` / `onImageLoadFailed` 与 URL 对齐，避免竞态。
- **UI 状态**：`MainUiState` 扩展为 `promptInputError`、`pipelineError`、`imageLoadError`；新一次生成开始时清空 `imageUrl`，避免失败后仍显示旧图。
- **Activity**：`generateImage` 传入 `strings` 中的空 prompt 文案；`buildStatusText` 合并状态与错误；`bindImagePreview` 用 `lastLoadedImageUrl` 去重加载，Coil `listener` 处理成功/失败/取消；保存流程 `finally` 恢复 Save 按钮状态。
- **OkHttp**：`NetworkModule` 增加 `callTimeout(90s)`，读写超时 45s，便于整体超时与错误提示一致。

## 构建与依赖（当日追加）

- **问题**：`MainActivity.kt` 使用 `import androidx.activity.viewModels` 与 `by viewModels()` 时编译报错 **Unresolved reference: viewModels**（`:app:compileDebugKotlin` 失败）。
- **原因**：`viewModels()` 由 **`androidx.activity:activity-ktx`** 提供；仅依赖 `lifecycle-viewmodel-ktx` 不会包含该 Activity 扩展。
- **修改**：在 `app/build.gradle.kts` 的 `dependencies` 中增加 `implementation("androidx.activity:activity-ktx:1.9.3")`。
- **验证**：本地执行 `./gradlew :app:assembleDebug`，**BUILD SUCCESSFUL**。
